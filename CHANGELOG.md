# Changelog

All notable changes to 歇一喵 are documented here.

The project uses `MAJOR.MINOR.PATCH` version numbers. Dates below refer to the
original local release history.

## [0.7.1] - 2026-07-29

### Changed

- Reframed the cat as a reliable, slightly witty graduate-student desk buddy.
- Renamed the care entry to “猫猫休息站”.
- Rewrote emotion weather, quiet break, friend support, note box, evening
  shutdown, and time-aware bubble copy in a friendship-oriented tone.
- Renamed interaction levels to 安静待机, 正常活动, and 活泼捣乱.
- Renamed evening options to 朋友式肯定, 讲个冷笑话, and 直接收工.
- Shifted the rest-station palette toward mint, light blue, and warm apricot.

### Quality

- Added checks that reject romantic, exclusive, or dependency-framed copy.
- Expanded the automated suite to 134 checks.

## [0.7.0] - 2026-07-29

### Added

- Eight new cat states: loaf, deep sleep, long stretch, held, note, backpack,
  quiet idle, and petting.
- Three pet activity levels and low-frequency time-aware speech bubbles.
- Growth-point outfits: apricot scarf, sleep cap, graduate backpack, and
  safety goggles with a wrench.
- Emotion weather, local note box, self-criticism reframing, and optional
  evening shutdown flow.

## [0.6.0] - 2026-07-29

### Added

- Four daily self-care cards that gate paid rewards without streaks or debt.
- 80-item reward library with free self-care, food, social, entertainment,
  outdoor, hobby, rest, personal, and venting categories.
- Permission slips, boundary phrases, reflection-stop coupon, and local mood
  landing.
- Fifty categorized confirmation messages for reminder actions.

## [0.5.0] - 2026-07-29

### Added

- Customizable global hotkey with conflict detection and fallbacks.
- Mixed-DPI, negative-coordinate, multi-monitor placement and cross-screen
  walking.
- Long-term growth points and spendable freedom points.
- To-do categories and simple/normal/important difficulty levels.

## [0.4.0] - 2026-07-28

### Changed

- Replaced the single walking pose with an eight-frame gait.
- Added a 50%–120% pet size control; default size changed to 70%.

## [0.3.0] - 2026-07-28

### Fixed

- Fixed the pet starting invisible with an unavailable global hotkey.
- Registered the hotkey independently of pet visibility.
- Made manual meeting mode session-only.
