# 隐私说明

最后更新：2026-11-03

“歇一喵”是一款完全在 Windows 本机运行的桌面程序。

## 不收集的内容

程序不包含账号系统、广告、遥测或分析服务，也不会访问网络。程序不会读取或采集：

- 姓名、联系方式或账号信息；
- 摄像头、麦克风、定位或通讯录；
- 文件内容、浏览历史或键盘输入内容；
- 腾讯会议、飞书会议等软件中的会议内容。

## 本地使用的信息

为实现功能，程序会在本机处理以下信息：

- Windows 最后一次键盘或鼠标输入的时间，用于判断电脑是否正在使用；
- 当前前台窗口和已运行进程的名称，用于全屏及会议保护；
- 用户自行填写的待办、分类、奖励、便签和设置；
- 提醒完成情况、今日小脚印、成长点与自由度；
- 桌宠大小、位置和显示器相关设置。

程序只判断输入时间和应用状态，不记录具体按键、鼠标轨迹、会议内容或屏幕画面。

## 数据保存位置

设置与用户内容保存在：

```text
%LocalAppData%\歇一喵\settings.json
```

数据不会自动上传。删除该文件夹即可清除程序保存的本地数据；执行前建议先退出程序。卸载或删除可执行文件不会自动删除该文件夹。

## 开机启动

用户启用开机自启动后，程序只为当前 Windows 用户写入启动项。关闭该设置会移除对应启动项。

## 反馈与日志

提交问题时，请不要直接上传自己的 `settings.json`。若确有必要，请先删除待办、便签、自定义奖励和其他个人内容。

## 说明变更

若未来版本增加联网、同步或新的数据处理行为，应在发布前更新本文档并在版本说明中明确标注。
