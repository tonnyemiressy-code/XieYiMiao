# 歇一喵 0.7.1 角色与语气设定

## 设计方向

- 主题：它不是监督者，也不模拟亲密关系；它是一只熟悉、可靠、有点贫嘴的研究生桌面搭子。
- 气质：五成可靠研究生搭子、三成有边界的朋友、两成轻微吐槽。
- 视觉：便签式猫猫休息站，使用奶油白、薄荷绿、浅天蓝、暖杏色与暖棕色。
- 动效：低刺激、带呼吸感，动作表达事件和情绪，不为装饰而持续打扰。
- 标志性叙事：小猫替用户暂存便签、理清线头，必要时把纸团拍进角落。

## 文案边界

- 可以听吐槽、讲冷笑话、给朋友式肯定，也可以提醒用户不要总欺负自己。
- 不使用“永远陪着你”“只属于你”“不会离开”“你只需要我”或“我会一直等你”等表达。
- 不营造排他、依赖、被需要或情感承诺，不模拟拥抱、依偎等亲密接触。
- 关怀文案保持短、直接、有生活感，不写过度柔软或煽情的长段落。
- 猫咪仍可被摸头、拖动、双击互动、抱便签、猫饼和发呆；这些属于桌宠动作，不代表亲密关系暗示。

## 不可改变的角色锚点

- 圆润蓬松的奶油白幼猫。
- 杏色耳尖和杏色蓬松尾巴尖。
- 暖棕色大眼睛、粉色小鼻子和小嘴。
- 薄荷绿项圈与浅蓝色水滴吊坠。
- 身体短小圆润，四肢短而自然，保持幼猫比例。
- 所有动作必须保持相同脸型、眼睛比例、毛色、项圈、吊坠和性格。

## 首批核心形态

从左到右、从上到下：

1. 揣手猫饼。
2. 蜷缩熟睡。
3. 醒来伸懒腰。
4. 被抱起时四脚自然悬空。
5. 抱住用户的纸条。
6. 背研究生小书包、拿钥匙准备回宿舍。
7. 安静坐着待机。
8. 被摸头后眯眼蹭手。

## 图像生成提示词

使用场景为桌面宠物角色设定与动画姿势审批图。输入图片一作为唯一身份锚点，输入图片二作为现有姿态和画风参考。生成一张横向 4×2 设定图，每格仅出现同一只完整的小猫，依次展示猫饼、熟睡、伸懒腰、被抱起、抱纸条、背包回宿舍、安静待机和摸头反应。保持奶油白毛发、杏色耳尖和尾尖、暖棕色眼睛、薄荷绿项圈、浅蓝水滴吊坠以及相同身体比例。采用柔和手绘 Q 版游戏角色插画，暖象牙色背景，无文字、标签、水印、额外角色或额外配饰。
